# يونس للمقاولات — معاينة تفاعلية

واجهة عربية RTL متجاوبة: `index.html` و`client.html` و`team.html` و`admin.html`.

تعمل جميعها على بيانات توضيحية مشتركة عبر localStorage في **المتصفح نفسه**؛ ومن دون API أو صلاحيات فعلية أو مدفوعات. يمكن تقديم طلب عرض سعر وتجربته من بوابة العميل وإدارته من لوحة المبيعات، وإضافة مشروع وتحريك تقدمه من بوابة الفريق، وتعديل محتوى الموقع ومراجعة سجلات محلية.

**تنبيه أخلاقي ومهني:** صور المشروعات للمظهر فقط؛ جميع الأرقام والمشروعات والأسماء بيانات مُختلقة للعرض ولا تُعد أعمالاً موثقة لشركة يونس. لا تضع بيانات شخصية أو حقيقية في نموذج عام تجريبي.

مرجع التصميم الوظيفي: [Hassan Allam](https://www.hassanallam.com/projects)، [Orascom](https://orascom.com/projects/) و[Turner](https://www.turnerconstruction.com/projects/). البنية والشعارات والنصوص مستقلة؛ لم يُنسخ كود أو صور ملكية من تلك المواقع.
