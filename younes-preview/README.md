# يونس للمقاولات | Younes Construction

Arabic RTL mobile-first interactive demo inspired by Hassan Allam's project architecture and Turner/REDCON's presentation patterns. No source, logos, photography or proprietary content copied. All company claims, projects, metrics, people, and financial figures are illustrative only. Pages: index.html, projects.html, services.html, contact.html, admin.html. Interactive contact-to-CRM, project management, progress, sales pipeline, tasks, staff roles, subcontractors, sample invoices, editorial title, audit events are browser-local (`localStorage`). NO real server authentication, persistent database, actual financial settlement, file uploads, notifications, or production readiness. Admin preview is intentionally publicly accessible; MUST be server-secured before production. All changes are in an isolated Git branch; do not merge or deploy without approval.

Sources: https://www.hassanallam.com/projects ; https://www.turnerconstruction.com/ ; https://redconcon.com/ . Production requirements: RBAC + authentication, project and client tenancy, PostgreSQL migrations, quote PDF generation, contracts, attachments, procurement, BoQ, certified payments, reporting, backup, integration and E2E tests.
